# Overview

This software is a simple C# console application that displays a greeting in the terminal. My goal is to practice writing, running, documenting, and publishing a small software project as I develop my programming skills.

The purpose of creating this software is to understand the basic structure of a C# console application, use the .NET command-line tools, and learn how to publish source code in a public GitHub repository.

**Software Demo Video:**  
[Software Demo Video](https://www.youtube.com/watch?v=VQgXgBL2U4I)

# Development Environment

I developed this software using Visual Studio Code and the .NET SDK. I used the integrated terminal in Visual Studio Code to create, build, and run the application.

The programming language used is C#. The program uses `Console.WriteLine()` to display the message `Hello World!` in the terminal.
